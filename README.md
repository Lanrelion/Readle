# Readle

An offline-first book management application built with React, Vite, and Dexie.js.

## Features
- Library Dashboard for physical and digital books
- Ebook Reader with sentence-level quote selection
- Offline support using IndexedDB (Dexie.js)
- Responsive design with Tailwind CSS v4

## Local Development
1. Clone the repo
2. Run `npm install`
3. Run `npm run dev`
